# 智能花卉养殖系统

本地单文件网页应用：花卉攻略库、花卉图鉴、种植打卡、病虫害用药查询、每日花语。
无需登录、无需联网（手机版已内嵌图片），数据保存在浏览器 localStorage。

---

## 🔧 日常修改流程

### 改代码 / 加花 / 改文案
1. 用记事本或 VS Code 打开 `智能花卉养殖系统.html`
2. 找到 `flowerGuideData`（花卉数据）或 `diseaseData`（病虫害数据），照着已有格式增删
3. 如果加新花：把对应照片放到 `img/`（拼音命名，如 `xinjia.jpg`），并在 `imageMap` 里加一行
4. 保存后运行：
   ```powershell
   powershell -ExecutionPolicy Bypass -File build_mobile.ps1
   ```
   会自动重新生成手机版

### 本地数据存在哪
- 种植打卡记录、主题选择：浏览器 localStorage（key: `myPlants`、`flowerTheme`）
- 清浏览器数据会丢，换浏览器/换手机不通用

## 🔌 单片机联动预留（后期用）

本应用是纯前端网页，接单片机（ESP32 / Arduino 等）常见两种方式：

### 方案 A：单片机自带 WiFi 热点（推荐新手）
- 单片机（ESP32）开 WiFi，手机连上后访问 `http://192.168.4.1`
- 在 HTML 里加一个"设备"模块，用 `fetch()` 读单片机的接口：
  - 温度湿度：`fetch('/sensor')` → 显示在打卡卡片上
  - 远程浇水：`fetch('/water?on=1')`
- 这部分以后在主版本里加新的 `<div>` 模块和 JS 函数即可

### 方案 B：电脑当服务器中转
- 电脑跑个小服务（Python Flask / Node），同时连单片机串口和网页
- 网页 fetch 本地服务的 `http://localhost:5000/api/...`

**预留位置**：以后加功能时，建议在 `home-module-wrap` 里加第 4 个卡片"🌡️ 我的花房设备"，单独建一个 `sub-page`，参考现有"种植打卡"模块的写法。

## 📱 手机版使用
- 把 `智能花卉养殖系统_手机版.html` 用微信/QQ 发到手机
- 安卓：微信里点开 → 右上角"···"→ 用其他应用打开 → 选浏览器
- iPhone：微信里点开 → 右上角"···"→ 用 Safari 打开
- 建议浏览器菜单里"添加到主屏幕"，以后像 App 一样用
